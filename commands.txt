OS LAB COMMANDS - WEEKS 1 TO 5
================================

WEEK 1 - CMD
systeminfo - Full system detail (Windows, CPU, RAM, BIOS, network)
hostname - Computer name
ver - Windows version
wmic os get osarchitecture - 32-bit ya 64-bit
wmic cpu get name - CPU model
wmic cpu get NumberOfCores,NumberOfLogicalProcessors - Physical cores aur logical processors
wmic computersystem get TotalPhysicalMemory - Total RAM in bytes
tasklist - Running processes ki list
tasklist | findstr notepad - Notepad process dhoondna
ipconfig - Basic network configuration
ipconfig /all - Full network detail
dir - Files aur folders ki list
cd - Folder change karna
cls - Screen clear karna
help - CMD built-in commands ki list

WEEK 2 - CMD (nayi commands)
tasklist /v - Detailed processes
taskkill /IM notepad.exe - Naam se process kill karna
taskkill /PID 1234 - PID se process kill karna (asal PID lagana)
whoami - Current user
echo %PROCESSOR_ARCHITECTURE% - CPU type
echo %NUMBER_OF_PROCESSORS% - Logical processors ki tadaad

WEEK 3 - CMD (nayi commands)
mkdir foldername - Folder banana
echo text > filename - File me text likhna
type filename - File ka content dikhana
copy previous.txt copy.txt - File copy karna
ren copy.txt newfile.txt - File rename karna
del filename.txt - File delete karna
ping 127.0.0.1 - Local network test

WEEK 4 - CMD (nayi commands)
bcdedit /enum - Boot configuration
bcdedit /enum {bootmgr} - Windows Boot Manager configuration
bcdedit /enum {current} - Current Windows Boot Loader configuration
echo %SystemRoot% - Windows folder
echo %SystemDrive% - System drive
sfc /verifyonly - System files check (repair nahi karta)
DISM /Online /Cleanup-Image /CheckHealth - Windows image health check

WINDOWS + R (RUN COMMANDS)
cmd - Command Prompt kholna
msinfo32 - System Information
dxdiag - DirectX Diagnostic Tool
devmgmt.msc - Device Manager
taskmgr - Task Manager
resmon - Resource Monitor
control - Control Panel
explorer - File Explorer
notepad - Notepad
calc - Calculator
winver - Windows version dialog
msconfig - System Configuration (Boot and Startup)
optionalfeatures - Windows Features
perfmon - Performance Monitor
sysdm.cpl - System Properties
eventvwr - Event Viewer
services.msc - Services console
powershell - PowerShell

WEEK 5 - POWERSHELL (CMD nahi)
Get-Process - Processes ki list
Get-Process notepad - Notepad dhoondna
Get-Process notepad | Select Id,ProcessName,CPU - Selected properties dikhana
Get-Process | Sort CPU -Descending - CPU time ke hisab se sort
Get-Process | Select -First 10 - Pehle 10 processes
Stop-Process -Id PID - Process rokna
Get-CimInstance Win32_Process - Process ki detail
Get-CimInstance Win32_Process | Select ProcessId,ParentProcessId,Name - Parent process info
Get-NetTCPConnection -LocalPort 8000 - Port 8000 check karna
netstat -ano | findstr :8000 - Port 8000 check karne ka doosra tareeqa
curl.exe -i http://127.0.0.1:8000/ - Local server ko HTTP request bhejna
Test-NetConnection example.com -Port 443 - TCP reachability test

WEEK 5 - LINUX C EXPERIMENTS (Linux ya WSL chahiye, CMD nahi)
nano process.c - File banana aur edit karna
gcc process.c -o process - C file compile karna
./process - Program run karna
fork() - Naya process banana
exec() - Program image replace karna
wait() - Parent ka child ka wait karna
zombie - Child khatam ho gaya magar parent ne collect nahi kiya
ps -eo pid,ppid,stat,comm | grep zombie - Zombie process check karna
